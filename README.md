# Backend and Advanced Communication Projects

This repository contains three folders, each with a different backend or full-stack project:

---

## 1. `backend`

A simple courses backend built with MongoDB.  
Features basic user and admin authentication.

---

## 2. `backend_with_Jwt`

An enhanced courses backend with secure JWT-based authentication.  
Provides improved security for user management and course operations.

---
